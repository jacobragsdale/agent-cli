# Agent trial: chains, round 2, 2026-09-30

Do agents walk from a failure to the line and the change behind it, now that
one-object verbs name their next command? Seven flows, each given to fresh
Sonnet 5.5 and Haiku 4.5 sessions, three runs per cell, with only the tool's
path, against the contoso world (loose matching), as
[How to run agent trials](../how-to/run-agent-trials.md) describes. Each
session ran headless from a directory outside the repository (`claude -p`
with `--setting-sources project --strict-mcp-config`, so no user hooks,
plugins or MCP servers).

## What the rounds found

- **The notes carry the new chains.** F8 and F9 took Haiku 4 to 6 calls:
  `run get` named `test list` or `file get`, and `test list` the line.
  F12's Haiku followed `import-error get` to the repository. No agent
  needed the suffix match explained: dd's `at` went straight into
  `ado file get`.
- **A prose note is not a signpost either.** In F13, Haiku had the rollout
  time from `deployment list` but reported the default last hour as the
  service's health since the rollout, in all nine runs of rounds 1 to 3:
  through a summary that said `--since a deploy` (round 2) and a note that
  said it in words (round 3). A note naming `agent-cli dd service get api
  --since <updated>` sent all three runs of round 4 back with the
  rollout's time. Sonnet passed the time itself every run.
- **The harness answered badly** where agents went past the answer: the
  `airflow-dags` root and its `requirements.txt` (Sonnet looked for where
  `contoso_crm` should be declared: 26 failed calls in round 1), a file's
  and a repository's commits, run 8814's logs, run 8815, an empty SLO list.
  All are recorded now.
- **Search misses agents repeated:** "build 8809" reached `pipeline list`
  and "run pipeline" `pipeline preview` (three times each), "service
  metrics performance" `metric list`, and "deployment rollout" the
  destructive `deployment restart`. Each is a labeled query now, landing
  first.
- **Pieces as flags:** Haiku tried `ado commit list api --path P` (now
  taken) and `import-error get customer_sync.py` twice (now taken).
- **Still open:** Haiku writes time arithmetic (`--until 2d-23h`, `--since
  2d-2h`; TODO), and tries resource synonyms (`pull-request`,
  `work-item`), which the usage error corrects in one call.
