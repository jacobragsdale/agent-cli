## Findings and what changed

1. **Fixture misses dominated the failed calls, and leaked the harness.**
   Agents chose their own windows and limits (`--since 2d`, `--limit 10`, dd
   `--since 2h`, WIQL with `--state New --state Active`, `dd monitor list
   service:api`) and were told "fixtures: no recorded answer…". Trials now run
   with `AGENT_CLI_FIXTURES_MATCH=loose` (set by `scripts/trial-env.sh`): a
   miss is answered by the closest recording of the same method and path, or
   a 404 when the path was never recorded. Tests stay strict. The world also
   records the unresolved-sprint-items query t01 asked.
2. **clap's tip pointed the wrong way.** `ado run logs 8809 --log-id 7` said
   "tip: to pass '--log-id' as a value, use '-- --log-id'". It now says
   `unknown flag --log-id; ado run logs takes --job --task --tail`, with
   "did you mean" when a flag is close.
3. **An id in the verb position suggested destructive commands first.** `ado
   run 8809` listed `run cancel` and `run retry` first. The first suggestion is
   now `agent-cli ado run get 8809`, and a failed lookup's suggestions list
   reads before writes and destructive commands.
4. **Search printed "(no command matches every word)" for most natural
   questions and missed several known queries.** Domain synonyms now count
   only for their own domain's commands (ado's "build" no longer lifts
   airflow runs), a question ranks writes below reads, "show" and "view" no
   longer count toward coverage, and the guess line prints only when the best
   hit misses most of the words: on the labeled queries it printed 148 times
   in 236, now 9. The twelve tasks and the searches agents typed are labeled
   queries. On the 236 labeled queries, top-1 went from 221 to 234 and top-5
   from 234 to 236. The two remaining misses are "v1.4.2 build" (`ado
   pipeline list` above `ado run list`) and t04's full sentence (`k8s pod
   logs` above `k8s pod list`).
5. **Housekeeping.** The world's README listed `AGENT_CLI_CONFIG` twice; the
   command reference is now generated from the registry, and every command
   line in the docs is checked against it.
